# Velocity and Average Velocity

Velocity describes how fast an object is moving and in what direction.

## 1. Average Velocity
**Average velocity** is the displacement divided by the time interval during which the displacement occurred.

### Formula
```
v_avg = Δx / Δt
```

## 2. Average Speed
Unlike velocity, **average speed** is the total distance divided by the total time.

## 3. Direction
Since velocity is a vector, we must specify direction (e.g., +x direction, North, or using an angle).

*Note: In 1D motion, the sign (+ or -) usually indicates the direction.*
