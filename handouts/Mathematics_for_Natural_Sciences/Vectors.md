# Vectors

In mathematics and physics, a vector is an object that has both a **magnitude** and a **direction**.

## 1. Vector Representation
Vectors are usually represented by arrows. The length of the arrow represents the magnitude, and the arrowhead represents the direction.

### Algebraic Form
A vector in 2D space can be written as:
```
A = (x, y) or A = xi + yj
```

## 2. Vector Addition
To add two vectors, we add their corresponding components.

If **A** = (x1, y1) and **B** = (x2, y2), then:
**A + B** = (x1 + x2, y1 + y2)

## 3. Dot Product
The dot product of two vectors results in a scalar.
```
A · B = |A||B| cos(θ)
```
Where θ is the angle between the two vectors.

*Important:* If the dot product is zero, the vectors are **orthogonal** (perpendicular).
